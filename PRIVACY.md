# Конфиденциальность

EatBefore спроектирован как **local-first** приложение.

## Принципы

- **Без регистрации.** Приложение полностью функционально без учётной записи.
- **Данные остаются на устройстве.** Продукты, партии, история, настройки хранятся
  локально в базе Room. Ничего не отправляется на серверы.
- **Без рекламных SDK и трекеров.** Аналитика поведения не собирается, третьим лицам
  данные не передаются.
- **Минимум разрешений.** На этапе Foundation runtime-разрешения не запрашиваются.
  В дальнейшем: камера — только для сканирования; уведомления — только для напоминаний
  о сроках; оба запрашиваются в момент использования с объяснением зачем.
- **Системный бэкап отключён** (`allowBackup=false`, правила извлечения исключают всё):
  резервное копирование выполняется только по явному действию пользователя (в roadmap).
- **QR/штрихкод — это данные, а не команда.** Содержимое кодов никогда не выполняется,
  ссылки не открываются автоматически.
- **Снимки для OCR не хранятся.** Распознавание срока выполняется on-device (ML Kit),
  снимок сохраняется во временный кеш и удаляется сразу после распознавания.
- **Отчёт о сбое никуда не уходит сам.** Ошибки записываются в текстовый файл во
  внутренней памяти приложения. Ни SDK сбора сбоев, ни автоматической отправки: файл
  покидает устройство только через системное «Поделиться» по явному действию
  пользователя, который перед этим видит его целиком. В отчёт попадает техническая
  часть — версия, модель устройства, стек вызовов, имя нечитаемого файла, — но не
  содержимое запасов, сроки и места хранения. Хранятся последние 20 записей;
  «Очистить» удаляет файл.

## Сеть (в будущих итерациях)

Интернет используется исключительно для поиска информации о товаре по штрихкоду через
`ProductCatalogProvider` (HTTPS, таймауты, кеширование). Отсутствие сети не мешает
добавлять и вести учёт продуктов вручную. Персональные данные в сетевые запросы и URL
не помещаются.

## Хранение чувствительных данных

Секреты и ключи в репозиторий не коммитятся и в резервные копии не включаются. Для
чувствительных ключей предусмотрен Android Keystore (по мере необходимости).
