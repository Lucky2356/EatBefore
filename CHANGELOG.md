# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Проект придерживается семантического версионирования.

## [Unreleased]

### Совместный доступ (двое в одном доме)
- **Запасы можно вести вдвоём.** Выберите в настройках папку, которая
  синхронизируется между устройствами (Google Диск, Яндекс.Диск и т. п.), и
  укажите ту же папку на втором телефоне — приложение будет обмениваться
  изменениями через неё. Без регистрации, без аккаунтов и без наших серверов:
  добавлять сервер ради этого означало бы отказаться от главного обещания
  приложения. См. [ADR-0004](docs/adr/0004-household-sharing.md).
- **Каждый телефон пишет только свой файл** `journal-<id>.json` и читает чужие.
  Один общий файл, куда дописывают все, потребовал бы блокировки, а её через
  облачный диск нет — два телефона затёрли бы правки друг друга.
- **Правила слияния**: события неизменяемы, поэтому повторный обмен ничего не
  меняет; у партий побеждает более свежее изменение, так что устаревший телефон
  не «воскресит» съеденное; места хранения сопоставляются по названию.
- Миграция базы **v1 → v2** (стабильные `uuid`, `device_id`). Данные при
  обновлении сохраняются — проверено тестом на реальной базе v1.
- Побочный выигрыш: **партии больше не дублируются** при повторном импорте
  одного и того же файла — ограничение, о котором честно писали в v1.3.0.
- Обмен не мгновенный: сначала папку синхронизирует облачный диск, потом второй
  телефон должен открыть приложение. Об этом сказано прямо в настройках.

### Каталог товаров
- **Поиск идёт по всем открытым базам сразу** (`product_type=all`): еда, косметика,
  бытовая химия и корма для животных. Раньше запрос уходил только в базу еды —
  шампунь или стиральный порошок не могли найтись в принципе. Проверено на
  реальных кодах: `3574661527925` и `8006540818824` раньше не находились, теперь
  находятся.
- **Российского бесплатного API с названиями товаров не существует** — это
  проверено, а не предположено: «Честный знак» отдаёт HTTP 451, Национальный
  каталог требует платный ключ, opengtindb мёртв, barcode-list.ru блокирует
  запросы, upcitemdb отвечает пустотой. Подробности и способ перепроверить —
  в [docs/CATALOG.md](docs/CATALOG.md).
- **Цепочка провайдеров** (`ChainedCatalogProvider`): источники опрашиваются по
  очереди, и «товара нет» больше не путается с «не смогли дозвониться» —
  в первом случае сразу предлагается ручной ввод, во втором повтор.
- **Отправка неизвестных товаров в общую базу**. Вводите название один раз —
  и штрихкод начинает распознаваться у всех, включая вас на другом телефоне.
  Требуется бесплатный аккаунт Open Food Facts (база не принимает анонимные
  записи); пароль хранится зашифрованным через Android Keystore и не попадает
  в бэкап. Каждая отправка подтверждается отдельно; уходят только штрихкод,
  название, бренд и объём.

### Единый стиль
- Отступы и радиусы вынесены в токены `Dimens` и `Shapes` — радиус скругления
  раньше гулял между 12, 14, 16 и 20 dp от экрана к экрану.
- Общие `ScreenScaffold` и `SectionCard` вместо копий в каждом экране: строка
  настроек, шапка и кнопка «назад» теперь описаны в одном месте. Переведены
  **все** экраны, включая сканер, распознавание срока и покупки.
- Строки настроек стали не ниже 48 dp — часть из них не дотягивала до
  минимального размера цели нажатия.

### Доделано
- **Настройки попадают в бэкап** (схема v2): тема, порог «скоро истекает», время
  напоминаний и тихие часы. Файлы старого формата по-прежнему импортируются.
- **Подтверждение для «выбросить»** — действие списывало партию в потери сразу
  по нажатию в меню.
- TODO.md приведён в соответствие с кодом: виджет, повтор покупки, baseline
  profile и retry там до сих пор числились невыполненными.

### Скорость
- **Baseline Profile**: приложение компилируется заранее, при установке, а не
  интерпретируется при первом запуске. Профиль (27 тыс. правил) генерируется модулем
  `:baselineprofile` и коммитится; на устройство его ставит `androidx.profileinstaller`.
  Добавлен `StartupBenchmark` для замера холодного старта. Процедура —
  [docs/BASELINE_PROFILE.md](docs/BASELINE_PROFILE.md).
- Для генерации в `EatBeforeApp` включён `testTagsAsResourceId`, у кнопок нижней
  навигации появились теги: UI Automator не видит семантику Compose, а поиск по тексту
  сломался бы на другой локали.

## [1.3.0] — 2026-07-16

Редизайн, удобство и подготовка к продакшену.

### Интерфейс
- **Карточка товара переработана**: «Открыть», «Уменьшить», «Закончилось» — три
  крупные кнопки, всегда видны. Раньше семь действий уезжали в горизонтальный
  список, и до «Изменить»/«Переместить» приходилось скроллить. Остальные действия —
  в меню «⋮». Количество получило явную кнопку правки вместо скрытого тапа по тексту.
- **Своя зелёная палитра по умолчанию** — приложение больше не красится в цвета
  обоев (Material You остаётся включаемым в настройках).
- Исправлена ошибка палитры: карточки были сиреневыми на зелёном фоне, потому что
  роли `surfaceContainer*` не были заданы и Material подставлял свои фиолетовые.
- **Названия сохраняются с заглавной буквы** («молоко» → «Молоко»), клавиатура
  сразу в режиме заглавной. Затрагивается только ручной ввод — названия из каталога
  сохраняются как опубликованы.

### Добавлено
- **Режим «из магазина»**: сканируйте товары подряд — известные добавляются сами,
  без диалога на каждый; неизвестные коды копятся и предлагаются к вводу в конце.
- **Сроки после вскрытия**: «открытое молоко — 3 дня». Поле для этого было в базе
  с самого начала, но его никто не заполнял.
- **Частые покупки** — товары, купленные не раз, добавляются в список одним тапом.
- **Автоматические копии**: ежедневное сохранение данных в выбранную папку. Данные
  живут только на телефоне, поэтому его потеря означала потерю всего.
- **Виджет** «Скоро испортится» на рабочий стол.
- **Кнопки в уведомлении**: «Открыть список» и «Не сегодня».
- **Импорт со слиянием** («Добавить к моим») и автоматическая копия перед импортом —
  раньше импорт затирал всё безвозвратно.

### Каталог и русские товары
Разобрана жалоба «не добавляется Tea Nic»: код исправен, в Open Food Facts есть
только один Tea Nic (лимон) и ~35 000 российских товаров всего. Проверено на пяти
реальных русских штрихкодах — добавляются автоматически.
- User-Agent приведён к требованиям OFF (у них лимит 15 запросов/мин на IP и право
  блокировать неопознанных клиентов).
- При 429/503 — короткий повтор с задержкой вместо мгновенной ошибки.
- Текст «товара нет в каталоге» стал честным и объясняет, что после ручного ввода
  повторный скан подставит товар сам, даже без интернета.

### Надёжность
- **Миграции Room**: подключён `MigrationTestHelper`, добавлен тест схемы и
  зафиксирована процедура в ARCHITECTURE.md — до этого изменение схемы уронило бы
  приложение у пользователей.
- Dependabot для зависимостей и GitHub Actions.

## [1.2.0] — 2026-07-16

Итог полного аудита проекта: найденные дефекты исправлены, добавлены недостающие
возможности, подключены инструменты качества.

### Добавлено
- **Редактирование продукта**: название, бренд, категория, срок годности и заметка
  правятся из карточки; изменение партии пишет событие в историю.
- **Фото товара** из каталога: крупное в карточке, миниатюрой в списке запасов.
- **Управление местами хранения**: свои места (имя + тип), переименование, выбор
  основного, скрытие (нельзя скрыть основное и последнее активное).
- **Английская локализация** (`values-en`) и правильные формы множественного числа
  в уведомлениях через `<plurals>`.
- Сканер: снекбар «Упаковка добавлена» теперь предлагает открыть добавленную партию.

### Исправлено
- **Даты в истории и карточке показывались по UTC** — до 03:00 МСК событие
  датировалось вчерашним днём. Везде используется локальная зона и локализованный формат.
- **Быстрые действия на главной срабатывали только по иконке**: тап по подписи
  («Сканировать», «Добавить вручную») ничего не делал. Кликабельна вся кнопка целиком.
- **Поле поиска в запасах стирало ввод**: оно управлялось значением с debounce 250 мс.
  Поле реагирует на каждый символ, задержка осталась только у фильтрации.
- **Отмена пропадала после отказа от «в список покупок?»** — снекбар «Отменить»
  не показывался, действие можно было отменить только через Историю.
- «Отменить последнее» больше не откатывает сам откат (компенсирующие события
  пропускаются).
- Неверная подпись у кнопки сортировки для TalkBack; иконкам-кнопкам добавлены
  описания (назад, сортировка, действия с местом).
- User-Agent запросов к Open Food Facts берётся из версии приложения.

### Качество
- **9 Compose-UI-тестов** сценариев из ТЗ (онбординг, добавление, списание+отмена,
  история, поиск, покупки→запасы, тема, бэкап) на реальном устройстве.
- **detekt + ktlint (spotless)** с конфигом и общим `.editorconfig`; оба шага в CI.
- **Пагинация истории**: список грузится страницами по 100 вместо всей таблицы.
- Unit-тесты: 83 (добавлены на редактирование и недельную динамику).

## [1.0.0] — 2026-07-15

Первый стабильный релиз: весь обязательный объём P0 реализован и проверен.

### Добавлено
- **Поддержка «Честного знака» (GS1)**: сканер понимает DataMatrix/QR-коды маркировки —
  извлекает GTIN (поиск товара в кеше/каталоге) и срок годности (AI 17/15), который
  автоматически подставляется в добавляемую партию или в форму ручного добавления.
  Полный GS1-парсер (AI 01/10/21/17/15/11/13/91-93, GS-разделители, `]d2`-префиксы),
  11 unit-тестов. Код трактуется строго как данные.
- **Аналитика**: экран со счётчиками (добавлено/использовано/выброшено/просрочено),
  долей «использовано вовремя», категориями отходов и регулярными покупками;
  периоды 7/30/365 дней и всё время.
- **Резервное копирование**: экспорт всех данных в JSON (версия схемы + counts для
  проверки целостности) и импорт с подтверждением замены; импорт атомарный —
  повреждённый файл не меняет данные; лимит размера файла 20 МБ. Кнопки в настройках
  (секция «Данные», SAF-диалоги системы).
- **Точное количество**: тап по числу в карточке продукта открывает ввод точного
  остатка (граммы/проценты/штуки).

### Исправлено
- Падение на Android 8–13: `LocalDate.ofInstant`/`LocalTime.ofInstant` требуют API 34/31 —
  заменены на `atZone(...)` (найдено линтом, критично для minSdk 26).
- Карточка «Товар найден» больше не перекрывает экран после «Добавить упаковку» —
  сканер сразу возвращается к работе.
- Перенос «Сканироват / ь» в быстрых действиях главного экрана.
- Дублирующийся заголовок «Количество» в форме добавления → «Единица измерения».

### Изменено (дизайн)
- Нижняя навигация: сканер — выделенная круглая центральная кнопка.
- Главный экран: цветные плитки статистики («Продуктов дома», «Скоро истекут»).
- Карточки запасов: иконка места хранения, крупные скругления, тональные поверхности.
- Раздел «Ещё»: История / Аналитика / Настройки (заглушек больше нет).

- **Список покупок**: экран с группировкой по категориям, отметка «куплено», ручное
  добавление, **«В запасы»** одним нажатием (купленное сразу возвращается в запасы —
  для связанного продукта добавляется партия, для свободного текста создаётся карточка).
  При списании продукта («закончилось»/«выбросить») предлагается добавить его в список.
  Повторное добавление того же товара **сливается по количеству**, а не дублируется;
  добавление из списанной партии пишет событие `ADDED_TO_SHOPPING_LIST` в историю.
- **Уведомления о сроках** (WorkManager): ежедневная фоновая проверка запасов и одно
  **пакетное** уведомление («Сегодня стоит проверить N продуктов» + разбивка
  просрочено/сегодня/скоро) — без спама. Настройки: вкл/выкл, время, за сколько дней
  предупреждать, тихие часы. Запрос POST_NOTIFICATIONS в момент включения. Экран настроек
  в разделе «Ещё». Чистая логика плана и тихих часов покрыта тестами; воркер проверен
  инструментальным тестом на устройстве.
- **OCR срока годности**: `ExpiryDateOcrProvider` на ML Kit text recognition (on-device);
  чистый `ExpiryDateParser` распознаёт форматы dd.MM.yyyy / dd.MM.yy / MM.yyyy / ISO /
  «dd MON yyyy» (EN+RU месяцы), различает «годен до» и «дата изготовления» по близости
  метки, ранжирует кандидатов по уверенности. Экран съёмки (CameraX ImageCapture) с
  показом исходного текста и выбором даты; подтверждение пользователем обязательно;
  снимок удаляется после распознавания. Кнопка «Распознать по фото» в форме добавления.
- **Сканер штрихкодов/QR/DataMatrix**: CameraX preview + ML Kit barcode (on-device,
  офлайн), подсветка области, фонарик, антидубль (окно 3 с), ручной ввод кода,
  корректная обработка отказа/отсутствия камеры.
- **Внешний каталог**: реализация `ProductCatalogProvider` на публичном API Open Food
  Facts (без ключа) — короткие таймауты, User-Agent, HTTPS, валидация недоверенных
  данных, обработка «не найдено»/ошибки без блокировки ручного ввода.
- **Кеширование**: найденный по коду товар сохраняется локально (source = SCAN_CACHE),
  повторный скан работает офлайн.
- Поток по коду: найден → «Добавить упаковку» (в место по умолчанию) или «Подробнее»
  (ручная форма с предзаполненным штрихкодом); не найден/ошибка → добавить вручную.

### Планируется
- OCR срока годности (ML Kit), уведомления, список покупок, аналитика, экспорт/импорт.
  См. [ROADMAP.md](ROADMAP.md).
