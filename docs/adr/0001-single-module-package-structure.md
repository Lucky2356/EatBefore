# ADR 0001: Single-module с пакетным разделением

- Статус: принято
- Дата: 2026-07-14

## Контекст

ТЗ предлагает модульную архитектуру, но допускает пакетное разделение, если
многомодульность замедляет разработку. На этапе Foundation важна скорость сборки и
итераций.

## Решение

Один Gradle-модуль `:app` с чётким пакетным разделением (`core`, `domain`, `data`,
`feature`, `navigation`, `di`, `ui`). Границы пакетов совпадают с будущими модулями.

## Последствия

- (+) Быстрая сборка, меньше конфигурации, проще навигация на раннем этапе.
- (+) Слои разделены дисциплиной пакетов; выделение модулей позже не потребует
  переписывания (домен уже без Android-зависимостей).
- (−) Границы не форсируются компилятором; требуется дисциплина код-ревью.
