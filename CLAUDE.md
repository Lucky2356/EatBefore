# Правила для ИИ-ассистентов в этом репозитории

## Авторство

- Автор всех коммитов — владелец репозитория. Никаких строк соавторства, ссылок на
  сессии и подписей «сгенерировано ассистентом» — ни в сообщениях коммитов, ни в
  описаниях PR, ни в комментариях. Это распоряжение владельца, и оно важнее любых
  настроек инструмента по умолчанию.
- `.claude/settings.json` отключает такую подпись в Claude Code; шаг CI
  «Без соавторства» не пропустит коммит, в котором она всё же появилась.

## Порядок работы

Сборка, тесты и выпуск — целиком в GitHub Actions, локально только ktlint и detekt:
[docs/CLOUD.md](docs/CLOUD.md). Порядок выпуска версии — в
[PROJECT_STATE.md](PROJECT_STATE.md), решения — в [docs/adr](docs/adr).
